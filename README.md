# Warp Real-Time Chat App

A real-time chat application built with **FastAPI** and **WebSockets**, following the [Warp University tutorial](https://docs.warp.dev/university/end-to-end-builds/building-a-real-time-chat-app-github-mcp-+-railway).

## Features
- **Real-time Messaging**: Instant communication via WebSockets.
- **Premium UI**: Modern dark-themed interface with Glassmorphism and smooth animations.
- **FastAPI Backend**: High-performance asynchronous Python server.
- **Dockerized**: Ready for deployment on cloud platforms like Railway.

## Local Setup

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the server**:
   ```bash
   python3 main.py
   ```

3. **Access the app**:
   Open `http://localhost:8000` in your browser.

## Deployment

This app is designed to be deployed on [Railway](https://railway.app/). Simply connect your GitHub repository and Railway will handle the building and hosting automatically.
